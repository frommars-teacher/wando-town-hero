# 완도ON 2 : 우리 마을 해결사

초등학교 4학년 사회의 ‘지역문제 해결방법을 탐색하고 장단점을 비교하여 선택하기’를 위한 정적 웹게임입니다.

## 게임 구조

마을 지도의 다섯 의뢰를 원하는 순서로 진행합니다.

1. 서로 다른 입장의 주민 3명 만나기
2. 서로 다른 조건의 현장 3곳 조사하기
3. 각 현장에서 자원 제한 안의 두 계획을 시험하고 결과 비교하기
4. 세 해결방법의 장점과 한계 비교 후 첫 계획 선택하기
5. 한정된 활동 자원을 배분하기
6. 새로운 상황 3회에 대해 의견 확인 → 대응 선택 → 실제 실행 계획 구성 → 결과 비교 → 유지 또는 재선택하기
7. 짧은 성찰과 배지 획득

해양은 추가 활동 장소, 교통은 실제 노선과 환승, 의료는 긴급성과 예약에 따른 연결 순서, 빈집은 집별 용도, 도로는 즉시 안전과 예방 관리 지점을 직접 조정합니다. 미니게임 오류는 수정할 수 있으며, 수정 기록과 노선 결과가 주민 의견에 반영됩니다.

## 평가

효과성·지속성·주민 배려·원인 해결력은 각각 100점입니다. 의뢰당 각 관점 최대 20점을 합산합니다.

- 첫 방법 20%, 현장 수행 15%, 최종 대응 30%, 정보 근거 10%, 실제 실행 계획 10%, 현장 실험 5%, 자원 배분 10%
- 성찰 응답은 점수에 영향을 주지 않습니다.
- 선택을 변경한 횟수나 변경 여부 자체에 가산점은 없습니다.
- S: 평균 85 이상, 모든 관점 75 이상
- A: 평균 75 이상, 모든 관점 60 이상
- B: 평균 60 이상, 모든 관점 40 이상
- 그 외 C

최종 평가서는 실제 첫 선택과 마지막 대응을 근거로 강점과 다시 살필 점을 보여 줍니다.

## 실행·저장

빌드, 서버 API, 로그인, 외부 라이브러리가 없습니다. `index.html`을 열거나 GitHub Pages에서 실행합니다. Pages 설정은 `main` / root입니다.

새 수업 기록은 `wando_town_hero_v2`에 저장합니다. 기존 v1 기록은 삭제하지 않고 보존합니다. 활동 구조가 달라 v1 완료 기록을 새 수업의 완료로 옮기지는 않습니다. 같은 브라우저·같은 사이트 주소로 다시 들어오면 진행 단계, 미니게임, 실험, 선택지 순서가 복원됩니다. 다른 기기·시크릿 창에는 자동으로 옮겨지지 않습니다. 브라우저 저장이 실패하면 화면에 알립니다.

완료한 의뢰는 점수를 한 번만 합산합니다. 다시 체험해도 첫 완료 기록과 평가서 점수는 바뀌지 않습니다. 초기화에는 두 확인 단계가 있으며, 확인창 바깥을 눌러도 기록이 사라지지 않습니다. 활동 기록은 JSON으로 내려받을 수 있습니다.

## 파일

- `index.html`, `styles.css`: 지도와 화면·반응형 연출
- `data.js`: 기존 다섯 의뢰와 해결방법 설명
- `lesson.js`: 주민, 현장, 새 상황, 평가 자료
- `experiments.js`: 두 계획의 자원 실험과 가상 결과 모형
- `responses.js`: 장소별 실행 계획과 피드백
- `app.js`: 진행, 저장, 점수, 랭크, 평가서
- `tests/rules.cjs`: 점수·랭크·실제 선택 피드백 등의 규칙 검증

## 수업 시간 검증의 범위

목표는 학생의 실제 독해와 판단을 포함한 30~40분 수업입니다. 강제 대기나 진행을 막는 타이머는 없습니다. 답을 아는 자동화의 빠른 클릭 검증은 학생 플레이 시간의 증거로 사용할 수 없습니다. 현재 자동화는 20분 미만에 완료할 수 있으므로 **‘빠른 학생도 최소 20분’ 조건은 검증되지 않았고, 절대적인 최소 시간을 보장하지 않습니다.** 실제 초4 학생의 사용 시간을 측정한 뒤 수업 적합성을 최종 판단해야 합니다.

의료와 도로 사례는 가상의 마을 문제 해결 학습입니다. 의료는 직접 진단하지 않고 보호자·119·의료진에게 도움을 연결하는 활동입니다. 도로 위험 현장에 직접 접근하는 활동은 없습니다.
