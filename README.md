# 완도ON 2 : 우리 마을 해결사 — v4

초4 사회 수업용 그림 모험 게임. 가로 태블릿과 데스크톱을 기준으로 제작했습니다.

## 실행
GitHub Pages 또는 정적 웹 서버에서 index.html을 여세요. 로그인과 외부 API는 없습니다. 음악은 사용자가 음악 켜기를 누른 뒤 시작합니다.

## 이번 변경
- 직접 만든 마을 지도와 다섯 현장 배경. 장소가 보이는 캐릭터 대화 화면.
- 단서 제시 퀴즈 제거. 미니게임 후 발견한 사실을 그림과 짧은 문장으로 바로 확인.
- 해변 분리 수거 / 움직이는 하천 쓰레기 잡기.
- 공사를 피하며 버스 이동과 주민 방문. 옆 칸 터치 또는 방향키. 길 힌트 제공.
- 필요한 물품 두 개를 챙겨 주민에게 도움 연결.
- 세 집 정리와 자유로운 가구 배치.
- 관을 돌리는 4×4 물길 퍼즐 세 구역, 물 흐름 검사와 힌트. 안전한 길 이동.
- 각 미니게임은 작은 목표 세 묶음. 강제 대기, 시간 제한, 게임오버 없음. 학생의 실제 소요 시간은 아직 측정하지 않았습니다.
- v3 완료 기록과 선택을 v4로 이어받고, 바뀐 미니게임은 처음부터 시작합니다. 이전 기록 원본은 보존합니다.

## 학습 흐름
주민 이야기 → 현장 게임 → 발견한 사실 → 장단점 비교와 첫 계획 → 선택 결과와 새 부탁 → 추가 게임 → 최종 선택 → 짧은 성찰 → 배지. 다섯 의뢰 후 네 관점과 실제 선택을 바탕으로 평가서를 보여줍니다.

## 파일
index.html, game.css, adventures.css, game-data.js, adventures.js, game.js가 현재 진입점입니다. assets의 WebP 그림과 OGG 음악을 사용합니다. 기존 app.js/styles.css 등은 이전 버전 보존 자료이며 현재 화면에서 불러오지 않습니다.
