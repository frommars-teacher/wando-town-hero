# 완도ON 2 : 우리 마을 해결사

초4 사회 학습을 짧은 대화와 그림 미니게임으로 풀어낸 마을 탐정 게임입니다.

## 새 그림 게임판 (v3)

글이 많고 어려웠다는 피드백을 반영해 화면을 다시 만들었습니다. 한 번에 한 주민의 짧은 대사를 보여 줍니다. 긴 조사·자원 실험·장단점 연결 문제는 새 화면에서 뺐습니다.

이야기 3장 → 미니게임 → 단서 제시 → 첫 계획 → 결과와 새 부탁 → 짧은 미니게임 → 다시 선택 → 성찰 → 배지 순서입니다. 다섯 의뢰를 원하는 순서로 플레이합니다.

- 바닷가: 쓰레기만 줍고 자연물은 남기기, 쓰레기가 오는 길 찾기
- 버스: 학교·병원 정류장 잇기, 시장 주민까지 연결하기
- 병원: 주민별 도움 연결하기, 위급한 도움부터 연결하기
- 빈집: 집마다 역할 찾기, 학생 공간과 조용한 시간 챙기기
- 도로: 수도관 조각 돌리기, 위험한 곳을 피해서 학교까지 가기

틀려도 게임오버나 감점 안내가 없습니다. 힌트를 보고 다시 할 수 있습니다. 세 첫 계획은 그림과 짧은 좋은 점·아쉬운 점으로 비교합니다. 다음 선택에서는 그대로 이어가거나 다른 도움을 더할 수 있습니다. 긴 최종 설명은 접힌 카드 안에 넣었습니다.

## 그림·소리

이 게임용 캐릭터 6명과 사물 3종을 AI로 제작했습니다. 웹용 그림 시트는 약 71KB입니다. 배경음악은 Bobjt의 CC0 곡 peacefull ville(2023) 전체 루프이며 웹용 파일은 약 80KB입니다. 출처와 제작 프롬프트는 assets/CREDITS.md에 있습니다.

음악은 처음에 꺼져 있습니다. 상단 버튼으로 켜고 끕니다. 음량은 낮게 설정하고 보이지 않는 탭에서는 멈춥니다. 켜져 있을 때 성공음도 짧게 재생됩니다. 그림과 음악 파일을 저장소에 포함하므로 플레이에 외부 API나 별도 로그인은 필요 없습니다.

## 점수와 저장

기존 효과성·지속성·주민 배려·원인 해결력 네 관점은 어린이 화면에서 ‘빨리 돕기·오래 지키기·이웃 챙기기·원인 찾기’로 풀어 씁니다. 각 관점은 의뢰당 최대 20점, 전체 100점입니다.

첫 계획 30%, 마지막 계획 50%, 활동 완료 20%(10점 척도의 8점)를 반영합니다. 미니게임은 모든 과제를 완료해야 다음 단계로 갈 수 있으며, 다시 시도한 횟수는 점수에 영향을 주지 않습니다. 선택을 바꿨다는 이유로 가산점을 주지 않습니다. 성찰도 채점하지 않습니다.

S는 평균 85 이상이면서 모든 관점 75 이상, A는 평균 75 이상·최저 60 이상, B는 평균 60 이상·최저 40 이상, 나머지는 C입니다.

wando_town_hero_v3에 진행 단계·미니게임·선택·순서를 저장합니다. v1·v2 기록은 그대로 보존하고 새 게임에 합산하지 않습니다. 완료한 의뢰의 보상은 한 번만 받고 첫 완료 점수는 다시 놀아도 바뀌지 않습니다. 초기화는 두 번 확인하며 바깥 클릭으로 지워지지 않습니다.

## 파일과 확인

index.html, game.css, game-data.js, game.js, assets/가 현재 실행 파일입니다. 이전 버전 파일은 보존하지만 index.html에서 불러오지 않습니다. tests/game-rules.cjs는 새 게임의 점수·랭크·문장 길이·단서 연결 45개 조합을 검사합니다. 이전 tests/rules.cjs와 VALIDATION.md는 v2용입니다.

이 버전은 글 부담을 줄이고 쉬운 놀이를 우선합니다. 30~40분이나 최소 20분을 보장하지 않습니다. 초4 학생의 재미·이해도와 실제 소요 시간은 별도 교실 검증이 필요합니다.
