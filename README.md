# 완도ON 2 : 우리 마을 해결사

초등학교 4학년 사회 **지역문제 해결방법 탐색** 수업용 정적 웹게임입니다.

학생은 마을 지도에서 5개 퀘스트를 자유롭게 골라 미니게임을 하고, 여러 해결방법 중 하나를 선택합니다. 선택에 따라 효과성·지속성·주민 배려·원인 해결력 능력치가 달라지고, 모든 퀘스트 완료 후 최종 랭크와 피드백이 표시됩니다.

## 실행
별도 빌드 과정이 없습니다. `index.html`을 브라우저에서 열거나 GitHub Pages로 배포하면 됩니다.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`

## 파일
- `index.html`: 화면 뼈대
- `styles.css`: UI/반응형 스타일
- `data.js`: 퀘스트·선택지·점수 데이터
- `app.js`: 게임 로직, 저장, 랭크, 피드백

## 저장 방식
진행 상황은 브라우저의 localStorage에 저장됩니다. 로그인이나 서버는 사용하지 않습니다.
